# Töötoa eesmärk ja ülesehitus

## Eesmärk

Töötoa eesmärk on anda osalejale praktiline kogemus Claude Code'i kasutamisest tarkvaraarenduses. Osaleja õpib olemasoleva rakenduse näitel, kuidas anda Claude Code'ile projekti kontekst, planeerida muudatusi enne koodi kirjutamist, katsetada turvaliselt ning kontrollida valminud tulemust.

Töötoa keskmes on Claude Code'i võimalused ja süsteemne tööviis. Pangaautomaatide asukoha rakendus on praktiliste harjutuste alus, mitte töötoa peamine õppeaine.

## Praktiline alus

Harjutused tehakse Vali-IT pangaautomaatide asukoha projektis:

- frontend: Vue.js;
- backend: Java ja Spring Boot;
- andmebaas: lokaalne PostgreSQL ja `vali_it` andmebaas;
- abimaterjalid: taskid, OpenAPI teenuste kontrakt, JSON näidised ja mock-pildid.

Kõik osalejad töötavad samas repositooriumis, kuid igaüks oma Git-harus. Vajaduse korral saab osaleja jätkata läbiviija checkpoint'ist uues harus, kaotamata oma varasemat tööd.

## Ülesehitus

Töötuba kestab neli akadeemilist tundi ja koosneb lühikestest sissejuhatustest ning praktilistest, üksteisele järgnevatest harjutustest.

Töötoa üldine käik:

1. projekti ja Claude Code'i töökeskkonnaga tutvumine;
2. projekti konteksti seadistamine;
3. ülesande planeerimine enne muudatuste tegemist;
4. kumulatiivsete arendusülesannete lahendamine;
5. muudatuste kontrollimine ja turvaline tagasikerimine;
6. korduvkasutatava skilli loomine;
7. valminud töö ülevaatus Claude Code'i abil;
8. MCP võimaluste tutvustus ja kokkuvõte.

## Promptide progressioon

Töötoa jooksul väheneb etteantud abi järk-järgult:

1. **Näita** — osaleja kasutab täisvalmis prompti.
2. **Tee koos** — osaleja täiendab või kohandab etteantud prompti.
3. **Tee ise** — osaleja koostab ülesande jaoks prompti iseseisvalt.

Eesmärk on, et osaleja ei õpiks ainult etteantud käske käivitama, vaid oskaks pärast töötuba Claude Code'iga iseseisvalt ja eesmärgipäraselt suhelda.

## Töötoa lõpuks

Osaleja oskab:

- anda Claude Code'ile ülesande lahendamiseks vajaliku konteksti;
- kasutada enne koodi muutmist plaanipõhist lähenemist;
- hinnata Claude Code'i plaani ja tehtud muudatusi;
- kasutada teste, diffi ja ülevaatust tulemuse kontrollimiseks;
- katsetada checkpoint'ide ja tagasikerimise abil;
- luua korduvkasutatava töövõtte skillina;
- selgitada, mis on MCP ja milleks seda kasutada.
