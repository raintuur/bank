# FEB-4 — Muuda kodu vaadet

## Kirjeldus

### Muuda kodu vaadet

- Muuda koduvaate komponent `HomeView.vue` alljärgnevaks
- Navigatsiooni menüüsse peaks jääma link "Kodu" (võib olla teksti või ikooni kujul)
- Võiks sellel lehel kuvada mingit teksti ("See on meie äge bank!") ja mingit pilti.
- Kustuta ebavajalikud hello world asjad
- Kasuta `router/index.js`'is `name` osas konventsiooni `homeRoute`

## Lisad

Taskiga on kaasas mockup kodu vaatest: navigatsioonis link "Kodu", tekst "See on minu pank" ja pilt.
